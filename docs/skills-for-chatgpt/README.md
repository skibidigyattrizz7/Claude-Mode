# Skills for ChatGPT

Copies of the skill guides Claude uses, put here so ChatGPT can read them (the originals live in Claude's local
.claude/skills, which is not committed). Open the SKILL.md in a folder and follow its workflow; `references/` holds
the deeper material it points to.

| Need | Skill |
|---|---|
| HUD, menus, overlays, scaling, touch vs desktop controls | game-ui-ux, threejs-game-ui-designer (HUD rules apply to canvas too; skip the Three.js parts) |
| Hits, dodges, impacts feeling punchy | game-feel |
| Framing both fighters, punch-ins, shake | camera-systems |
| Frame rate (measure first, then fix the real bottleneck) | performance-optimization |
| One coherent look for photo cut-outs + vector FX | create-game-assets |
| Sound mix, ducking under dialogue | audio-design |
| Proving it works before saying it's done | verification-before-completion |

Also read the owner's "looks vibecoded" list in CLAUDE.md before any UI change.
